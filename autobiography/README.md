# 나의 자서전

어르신이 질문에 하나씩 답하다 보면 한 권의 책이 되는 자서전 쓰기 앱입니다. K-STAR 현황판, 융합전공 현황판과 **완전히 독립된 별도 앱**입니다.

- 로그인이 없습니다. 처음에 성함만 적으면 바로 시작합니다(태어난 해·고향은 적지 않아도 됩니다).
- 10개 장(태어나고 자란 곳 → 남기고 싶은 말)에 질문이 5개씩, 모두 50개 들어 있습니다. 장마다 "직접 질문 만들기"로 질문을 더 넣을 수 있습니다.
- 첫 화면 "이어서 쓰기" 단추를 누르면 아직 답하지 않은 다음 질문으로 바로 갑니다.
- 질문 화면
  - 🔊 **질문 소리로 듣기**: 질문을 소리 내어 읽어줍니다.
  - 🎤 **말로 쓰기**: 말하는 대로 글자로 받아 적습니다(크롬·사파리 등 지원하는 브라우저에서만 됩니다. 안 되는 기기에서는 자판의 마이크 단추를 쓰라고 안내합니다).
  - 📷 **사진 넣기**: 한 질문에 사진을 3장까지 넣을 수 있습니다. 긴 쪽을 1280px로 줄여서 저장합니다.
  - 글을 쓰는 동안 자동으로 저장됩니다.
- **📖 내 책 보기**: 답한 내용이 표지, 차례, 장별 본문과 사진으로 모여 책처럼 보입니다. "인쇄 · PDF" 단추로 인쇄하거나 PDF로 저장할 수 있고(장마다 새 쪽에서 시작), "글 보내기"로 글만 카카오톡 등에 보낼 수 있습니다.
- **⚙️ 설정**: 글자 크기(보통/크게/아주 크게), 내 정보 고치기, 보관 파일 만들기/불러오기, 전부 지우기(두 번 확인).
- 화면 이동을 주소 뒤 `#`으로 하므로 안드로이드 뒤로가기 단추를 눌러도 앱이 꺼지지 않고 전 화면으로 돌아갑니다.

## 카카오톡으로 링크 보내기

- 링크 뒤에 `?name=성함&from=보내는사람`을 붙이면 첫 화면에 성함이 미리 채워지고 "💌 막내아들(이)가 보내드리는 선물이에요"가 보입니다.
  예: `https://kjstkd-autobiography.vercel.app/?name=김영자&from=막내아들`
- 카카오톡 안 브라우저에서 열리면 자동으로 휴대폰의 인터넷 앱(크롬·사파리)으로 다시 엽니다(`kakaotalk://web/openExternal`). 안 되면 화면에 방법을 안내합니다. 카톡 안에 저장한 자료는 인터넷 앱과 따로 놀고 카톡 캐시를 지우면 사라지기 때문입니다.
- 첫 화면에 "바탕화면에 단추 만들기" 안내가 나옵니다. 아이폰 사파리는 7일 동안 열지 않은 사이트의 저장 자료를 지울 수 있는데, 홈 화면에 추가한 앱은 예외라서 아이폰에서는 꼭 해두어야 합니다.
- 이야기를 하나라도 쓰면 첫 화면에 일주일마다 "💾 보관 파일 보내기" 안내가 나옵니다. 누르면 공유 창이 떠서 카카오톡으로 가족에게 파일을 바로 보낼 수 있습니다. 받은 가족은 같은 링크를 열어 설정 → "보관 파일 불러오기"로 책을 볼 수 있습니다(안드로이드 크롬이 `.json` 공유를 막아서 파일은 `.txt`로 만듭니다).

## 구글 시트 자동 저장

어머니가 쓰시는 이야기를 가족의 구글 스프레드시트에 자동으로 저장합니다. 설치 방법은 `apps-script.gs` 맨 위에 있습니다.

- **서버**: `apps-script.gs`를 가족 구글 계정의 Apps Script에 붙여넣고 웹 앱으로 배포합니다. 글은 스프레드시트 "나의 자서전"의 "이야기" 탭에 한 질문당 한 줄로 저장됩니다(순서·장·질문·이야기·사진·고친 때). 사진은 드라이브 폴더 "나의 자서전 사진"에 저장되고, 시트에는 그 사진 링크가 들어갑니다.
- **링크**: Apps Script에서 `링크만들기` 함수를 실행하면 링크 두 개가 나옵니다.
  - 어머니용 `?s=배포id&k=열쇠&name=&from=` — 이 링크로 열면 그 휴대폰이 자동 저장을 시작합니다.
  - 보기용 `?s=배포id&k=열쇠&view=1` — 시트의 이야기를 받아와 책으로 보여주기만 하고, 시트에는 쓰지 않습니다. 앱을 열 때마다 최신 내용을 받아옵니다.
- **보안**: 서버 주소와 열쇠는 이 공개 저장소에 없고 링크에만 있습니다. 앱은 받아둔 뒤 주소창에서 지웁니다. 서버는 열쇠가 맞는 요청만 받습니다. 보관 파일에는 열쇠를 넣지 않습니다.
- **동작**: 고칠 때마다 3초 뒤에 보냅니다(사진은 한 장씩 먼저 올린 뒤 글을 보냄). 인터넷이 끊겼으면 1분마다, 그리고 다시 연결될 때 보냅니다. 첫 화면에 "☁️ 아들 종수에게 자동으로 저장됐어요 ✓"처럼 상태가 나옵니다. 자동 저장이 잘 되고 있으면 "보관 파일 보내기" 안내는 나오지 않습니다.
- **휴대폰을 바꿨을 때**: 새 휴대폰에서 어머니용 링크를 다시 열면, 그 휴대폰에 쓴 이야기가 없는 경우 시트에 있던 이야기와 사진을 받아옵니다. 설정 → "시트에서 이야기 받아오기"로도 할 수 있습니다.
- 앱에서 지운 사진은 시트의 링크에서만 빠지고 드라이브 파일은 남습니다. "모든 이야기 지우기"는 휴대폰 안의 이야기만 지우고 시트는 건드리지 않습니다.

## 저장 방식

- 이야기와 사진은 **그 기기의 브라우저 안(IndexedDB)**에 저장됩니다. 위의 자동 저장 링크로 열었을 때만 구글 시트로도 보냅니다. IndexedDB를 쓸 수 없으면 localStorage에 저장합니다.
- 쓰는 중인 글은 곧바로 localStorage에도 적어두어서, 글을 쓰자마자 앱을 닫아도 마지막 몇 글자가 빠지지 않습니다.
- 휴대폰을 바꾸거나 잃어버리는 경우에 대비해 설정 화면의 "보관 파일 만들기"로 `.json` 파일을 내려받아 가족에게 맡겨두는 방식입니다. 다른 기기에서 "보관 파일 불러오기"로 되살릴 수 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (질문 목록은 위쪽 `CHAPTERS`) |
| `manifest.json` | 앱 설치 정보 |
| `sw.js` | 아이콘·이미지만 저장해두는 서비스 워커 |
| `icon-180.png` `icon-192.png` `icon-512.png` | 홈 화면 아이콘 |
| `og-image.png` | 카카오톡 미리보기 이미지 |
| `apps-script.gs` | 구글 시트 자동 저장 서버 (구글 Apps Script에 붙여넣는 코드) |
| `vercel.json` | 이 폴더를 따로 Vercel 프로젝트로 배포할 때 쓰는 캐시 설정 |

## 질문 고치기

`index.html`의 `CHAPTERS`에서 질문 문구를 바꿀 수 있습니다. 답은 `장id:번호`(예: `child:0`)로 저장되므로 **이미 쓰고 있는 분이 있을 때 질문 순서를 바꾸거나 중간 질문을 지우면 안 됩니다.** 그러면 이미 쓴 답이 다른 질문에 붙습니다. 새 질문은 각 장의 맨 뒤에 추가하세요.

## 배포

- 실제 주소: https://kjstkd-autobiography.vercel.app/ (K-STAR·융합전공과 다른 Vercel 프로젝트)
- Vercel에서 **Add New → Project**로 이 저장소를 가져오고, 프로젝트 이름은 `kjstkd-autobiography`, **Root Directory**는 `autobiography`, Framework Preset은 `Other`로 둡니다. Vercel은 `main` 브랜치를 배포하므로 이 폴더가 `main`에 있어야 합니다.
- 프로젝트 이름을 다르게 지었다면 `index.html`의 `og:url`·`og:image`와 위 주소를 바꿔야 카카오톡 미리보기가 나옵니다.

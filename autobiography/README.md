# 나의 자서전

어르신이 질문에 하나씩 답하다 보면 한 권의 책이 되는 자서전 쓰기 앱입니다. K-STAR 현황판, 융합전공 현황판과 **완전히 독립된 별도 앱**입니다.

- 로그인이 없습니다. 처음에 성함만 적으면 바로 시작합니다(태어난 해·고향은 적지 않아도 됩니다).
- 10개 장(태어나고 자란 곳 → 남기고 싶은 말)에 질문이 5개씩, 모두 50개 들어 있습니다. 장마다 "직접 질문 만들기"로 질문을 더 넣을 수 있습니다.
- 첫 화면 "이어서 쓰기" 단추를 누르면 아직 답하지 않은 다음 질문으로 바로 갑니다.
- 질문 화면
  - 🔊 **질문 소리로 듣기**: 질문을 소리 내어 읽어줍니다.
  - 🎤 **말로 쓰기**: 말하는 대로 글자로 받아 적습니다(크롬·사파리 등 지원하는 브라우저에서만 됩니다. 안 되는 기기에서는 자판의 마이크 단추를 쓰라고 안내합니다).
  - 📷 **사진 넣기**: 한 질문에 사진을 3장까지 넣을 수 있습니다. 긴 쪽을 1280px로 줄여서 저장합니다.
  - 글을 쓰는 동안 자동으로 저장됩니다.
- **📖 내 책 보기**: 답한 내용이 표지, 차례, 장별 본문과 사진으로 모여 책처럼 보입니다. "인쇄 · PDF" 단추로 인쇄하거나 PDF로 저장할 수 있고(장마다 새 쪽에서 시작), "글 보내기"로 글만 카카오톡 등에 보낼 수 있습니다.
- **⚙️ 설정**: 글자 크기(보통/크게/아주 크게), 내 정보 고치기, 보관 파일 만들기/불러오기, 전부 지우기(두 번 확인).
- 화면 이동을 주소 뒤 `#`으로 하므로 안드로이드 뒤로가기 단추를 눌러도 앱이 꺼지지 않고 전 화면으로 돌아갑니다.

## 저장 방식

- 이야기와 사진은 **그 기기의 브라우저 안(IndexedDB)**에만 저장되고, 서버로 보내지 않습니다. IndexedDB를 쓸 수 없으면 localStorage에 저장합니다.
- 쓰는 중인 글은 곧바로 localStorage에도 적어두어서, 글을 쓰자마자 앱을 닫아도 마지막 몇 글자가 빠지지 않습니다.
- 휴대폰을 바꾸거나 잃어버리는 경우에 대비해 설정 화면의 "보관 파일 만들기"로 `.json` 파일을 내려받아 가족에게 맡겨두는 방식입니다. 다른 기기에서 "보관 파일 불러오기"로 되살릴 수 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (질문 목록은 위쪽 `CHAPTERS`) |
| `manifest.json` | 앱 설치 정보 |
| `sw.js` | 아이콘·이미지만 저장해두는 서비스 워커 |
| `icon-180.png` `icon-192.png` `icon-512.png` | 홈 화면 아이콘 |
| `og-image.png` | 카카오톡 미리보기 이미지 |
| `vercel.json` | 이 폴더를 따로 Vercel 프로젝트로 배포할 때 쓰는 캐시 설정 |

## 질문 고치기

`index.html`의 `CHAPTERS`에서 질문 문구를 바꿀 수 있습니다. 답은 `장id:번호`(예: `child:0`)로 저장되므로 **이미 쓰고 있는 분이 있을 때 질문 순서를 바꾸거나 중간 질문을 지우면 안 됩니다.** 그러면 이미 쓴 답이 다른 질문에 붙습니다. 새 질문은 각 장의 맨 뒤에 추가하세요.

## 배포

융합전공 앱처럼 Vercel에서 새 프로젝트를 만들고 Root Directory를 `autobiography`로 두면 별도 주소로 배포됩니다. 주소가 정해지면 `index.html`의 `og:image`를 전체 주소로 바꿔야 카카오톡 미리보기가 나옵니다.

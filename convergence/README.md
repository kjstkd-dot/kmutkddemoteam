# 융합전공 이수 현황판

융합전공 이수 조건 추적관리 프로그램입니다. K-STAR 현황판과 같은 구조로 만들었습니다.

- 학생은 학번과 비밀번호로 들어와 자신의 이수학점과 충족 여부를 확인하고, 이수한 과목을 스스로 등록·수정합니다.
- 관리자는 전체 학생을 충족/미충족으로 보고, 학생 대신 과목이나 이수정보를 고치거나 비밀번호를 초기화합니다.
- 휴대폰에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 반영된 규정

계명대학교 **"융합전공 이수 규정"**과 **"첨단분야 혁신융합대학사업 학사 운영 내규"**를 기준으로 만들었습니다.

- 제4조② 핵심과목(최대 3과목/9학점)을 이수했는지 과목명으로 자동 인식합니다.
- 제7조① 복수전공: 33학점(핵심과목 포함) 이상
- 제7조② 부전공: 15학점(핵심과목 포함) 이상 + 제1전공 54학점(부전공 1개) 또는 42학점(부전공 2개 이상) 이상
- 제5조 이수신청 자격: 인정학기 3학기 이상 (신청 가능 여부만 안내, 실제 EDWARD 신청은 학교 시스템에서 진행)
- 마이크로디그리(제5조, 별표1·별표2): 과정을 선택하고 이수학점을 입력하면 과정별 기준 학점과 비교합니다.

학생은 홈 화면의 "이수정보 수정"에서 이수형태(복수전공/부전공)·인정학기·제1전공 이수학점·마이크로디그리 과정을 입력합니다. 이 값에 따라 충족 여부 계산 기준이 자동으로 바뀝니다.

## 이수 조건 채우기 (중요)

`index.html` 안에서 아래 두 값만 실제 값으로 바꿔주세요. 나머지 숫자(33/15/54/42/9학점 등)는 규정에 정해진 값이라 그대로 두면 됩니다.

```js
var TRACK_NAME = '(융합전공명을 입력하세요)';
var CORE_COURSES = [
  { name:'핵심과목1', credits:3 },
  { name:'핵심과목2', credits:3 },
  { name:'핵심과목3', credits:3 }
];
```

- `TRACK_NAME`: 화면 위쪽에 표시되는 융합전공 이름
- `CORE_COURSES`: 제4조②에 따라 지정된 핵심과목 이름·학점 (최대 3과목). 학생이 과목을 추가할 때 이 이름과 정확히 같게 입력하면 자동으로 핵심과목으로 인식됩니다.

마이크로디그리 과정 목록(`MICRODEGREE_PROGRAMS`)은 별표1·별표2 내용을 그대로 넣어뒀습니다. 컨소시엄 대학·과정이 바뀌면 이 배열을 고쳐주세요.

이 앱에 반영되지 않은 부분: 제3장 학점교류(컨소시엄 대학 간 수학신청·성적 인정)는 신청/승인 절차라서 "이수학점 추적"과는 성격이 달라 담지 않았습니다. 필요하면 별도로 추가할 수 있습니다.

## 자료 저장 연결

`index.html` 위쪽의 아래 줄에 구글 Apps Script 웹 앱 주소를 넣으면 서버 저장으로 바뀝니다. 설치 방법은 `apps-script.gs` 맨 위 설명을 참고하세요.

```js
var API_URL = '';
```

비워두면 그 기기 안에만 저장됩니다(시험용).

K-STAR 앱과 같은 Apps Script 배포를 재사용해도 됩니다. 컬렉션 이름 앞에 `cvg_` 를 붙여두어서 K-STAR 자료(`students`, `admins` 등)와 겹치지 않습니다.

## 첫 사용 순서

1. 관리자 탭에서 "처음이신가요? 비밀번호 설정하기"로 첫 관리자 계정을 만듭니다. (첫 관리자는 등록코드 없이 만들 수 있어요)
2. 관리자 화면의 "관리자 설정"에서 등록코드를 정해두면, 두 번째 관리자부터는 그 코드가 있어야 등록할 수 있습니다.
3. 학생들은 각자 학번으로 비밀번호를 설정하고 로그인해서 이수한 과목을 입력합니다.

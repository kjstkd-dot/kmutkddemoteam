# 융합전공 이수 현황판

융합전공 이수 조건 추적관리 프로그램입니다. K-STAR 현황판과 같은 구조로 만들었습니다.

- 학생은 학번과 비밀번호로 들어와 자신의 이수 학점과 구분별(핵심/선택/캡스톤 등) 충족 여부를 확인하고, 이수한 과목을 스스로 등록·수정합니다.
- 관리자는 전체 학생을 충족/미충족으로 보고, 학생 대신 과목을 고치거나 비밀번호를 초기화합니다.
- 휴대폰에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 이수 조건 채우기 (중요)

지금 들어있는 트랙명·총 이수학점·구분별 필요학점은 **예시 값**입니다.
`index.html` 안에서 아래 블록을 찾아 실제 조건으로 바꿔주세요.

```js
var TRACK_NAME = '(예시) 데이터사이언스 융합전공';
var TOTAL_MIN = 39;
var CATEGORIES = [
  { code:'CORE', name:'융합전공 핵심(필수) 교과', min:15 },
  { code:'ELEC', name:'융합전공 선택 교과', min:18 },
  { code:'CAP',  name:'캡스톤/설계 교과', min:6 }
];
```

- `TRACK_NAME`: 화면 위쪽에 표시되는 전공(트랙) 이름
- `TOTAL_MIN`: 졸업에 필요한 총 이수학점
- `CATEGORIES`: 학점을 나눠서 채워야 하는 구분들. `code`는 내부 식별자(영문), `name`은 화면에 보이는 이름, `min`은 그 구분에서 최소로 채워야 하는 학점입니다. 구분을 더 추가하거나 줄이려면 이 배열의 줄을 더하거나 빼면 됩니다.

과목을 특정 지정 과목 목록으로만 제한하고 싶거나(예: "이 6과목 중 4개 이상"), 참여학과별로 균형 학점을 요구하는 등 조건이 더 복잡하다면 알려주시면 그 로직도 추가해 드릴 수 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.json` | 앱 설치 정보 |
| `sw.js` | 오프라인 동작 |
| `icon-180.png` `icon-192.png` `icon-512.png` | 홈 화면 아이콘 |
| `apps-script.gs` | 자료 저장 서버 (구글 Apps Script 에 붙여넣는 코드) |

## 자료 저장 연결

`index.html` 위쪽의 아래 줄에 구글 Apps Script 웹 앱 주소를 넣으면 서버 저장으로 바뀝니다. 설치 방법은 `apps-script.gs` 맨 위 설명을 참고하세요.

```js
var API_URL = '';
```

비워두면 그 기기 안에만 저장됩니다(시험용).

K-STAR 앱과 같은 Apps Script 배포를 재사용해도 됩니다. 컬렉션 이름 앞에 `cvg_` 를 붙여두어서 K-STAR 자료(`students`, `admins` 등)와 겹치지 않습니다.

## 첫 사용 순서

1. 관리자 탭에서 "처음이신가요? 비밀번호 설정하기"로 첫 관리자 계정을 만듭니다. (첫 관리자는 등록코드 없이 만들 수 있어요)
2. 관리자 화면의 "관리자 설정"에서 등록코드를 정해두면, 두 번째 관리자부터는 그 코드가 있어야 등록할 수 있습니다.
3. 학생들은 각자 학번으로 비밀번호를 설정하고 로그인해서 이수한 과목을 입력합니다.
